# Dominic Liriano — portfolio

Static site served by GitHub Pages at https://javajaiden.github.io/dominic-liriano/. Every page is plain HTML in this repo (`index.html`, `experience/`, `projects/`, `project/<slug>/`, `contact/`), with images and files in `assets/`. The interactive sections (experience cards, viewers) are server-rendered HTML that `assets/site.js` makes interactive.

The pages are built for the `/dominic-liriano/` path. To move the site to domliriano.com, rebuild it for the domain root and add a `CNAME` file.
